About the project

Support answers with an evidence boundary.

Verified Support Assistant (VSA) is an open, synthetic demonstration of citation-first customer support. It optimizes for grounded behavior and inspectability rather than pretending to have account access.

How verification works

  1. The request is checked for account actions, sensitive information, prompt injection, and unsupported domains.
  2. TF-IDF retrieval ranks a versioned corpus of twelve synthetic support policies.
  3. Low-confidence matches are refused instead of answered.
  4. Supported answers disclose only the policy documents actually cited in the answer.

Measured behavior

The deterministic benchmark contains 25 answerable and 15 required-refusal cases.

What VSA can do

  • Answer questions established by shipping, return, refund, warranty, payment, security, international-order, and gift-card policies.
  • Link each supported answer to an inspectable in-app policy page.
  • Run deterministically without paid model calls, or use optional CoreWeave Forge Serverless Inference.
  • Send optional traces to Weave for observability and evaluation.

Limits and privacy

  • VSA has no customer database, order system, payment access, or transaction tools.
  • The policies and evaluation data are synthetic and are not retailer commitments.
  • Questions are sent to this application server. The browser does not save question history.
  • Optional inference and tracing should be enabled only with an approved W&B project and data policy.
