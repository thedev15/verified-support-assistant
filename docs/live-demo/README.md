# Live question-and-verification evidence

This directory is generated by `scripts/capture_live_demo.py` from the real
Verified Support Assistant browser page and API.

The committed evidence was captured inside a private, bounded CoreWeave
Sandbox. `sandbox-capture.json` records the Sandbox ID, capture environment,
capture time, and hard expiry. Private capture verifies the deployed runtime
without claiming that the application had a durable or public endpoint.

For each of the 40 versioned cases in `data/eval_set.json`, the script:

1. opens the deployed application in Chromium;
2. types the actual benchmark question into the visible form;
3. clicks **Verify answer**;
4. waits for the `/api/ask` response to render;
5. captures the question, answer or refusal, verification badge, and citations;
6. compares the observed refusal and cited document with the expected case; and
7. records the exact API payload, screenshot hash, dimensions, and byte size.

The capture fails unless all 40 cases are present, refusal accuracy and
expected-document retrieval are both 100%, all screenshot hashes are unique,
and the evidence archive passes its CRC check.

## Reproduce

```bash
python -m pip install -e ".[dev]" playwright
python -m playwright install chromium
python scripts/capture_live_demo.py --base-url http://localhost:8000
```

To repeat the same bounded private-Sandbox workflow:

```bash
python -m pip install "cwsandbox[wandb]>=1.14,<2"
python scripts/deploy_sandbox_demo.py --lifetime-minutes 90 --private-capture
```

`verified-support-live-evidence.zip` contains the 40 PNGs, full JSON responses,
verification summary, and this methodology.
